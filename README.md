# Login Page

A simple and responsive login page built with **HTML5** and **CSS3**.

## Live Demo

[View Live Demo →](https://sadra00sa.github.io/Purple-Log-in/)

## Features

* Responsive login layout
* Floating input labels
* Hover effects
* CSS transitions and animations
* Gradient background

## Technologies

* HTML5
* CSS3

## Purpose

This project was created to practice HTML forms, CSS layouts, positioning, transitions, and basic animations.
